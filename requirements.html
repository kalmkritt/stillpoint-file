system requirements

operating system
Windows 10 or later (64-bit).
memory
minimum 2GB RAM. 4GB+ recommended.
storage
under 10MB. stillpoint is lightweight by design.
processor
any modern 64-bit processor. intel or amd.
permissions
some features require administrator privileges for system-level access.
tested on
developed and tested on Lenovo IdeaPad 5 2-in-1 14AHP9 with AMD Ryzen 7 8845HS and Radeon 780M graphics.
