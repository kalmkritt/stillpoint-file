faq

is stillpoint safe?
yes. stillpoint reads system data to display it. it doesn't send anything anywhere.
why does it need admin rights?
some optimizations require elevated access to modify system settings. you'll be prompted when needed.
will it slow down my pc?
no. stillpoint is built in rust and uses minimal resources itself. the irony of an optimizer that tanks your performance wasn't lost on me.
is it open source?
no. stillpoint is proprietary. personal use only.
will it always be free?
yes.
does it work on mac or linux?
windows only for now.
how do i report bugs?
open an issue on github.
